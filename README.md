# CobaltSoftwares
Collect of tiny softwares that I created with AI.
All softwwares written in Python.

## CobaltArchiver
A file extraction and compression software based on 7Z.
It doesn't offer any significant advantage—just lacks a file explorer, which is precisely what I needed.

## CobaltEncrypter
This software provides a graphical interface for encrypting and decrypting files using the serial number of a USB drive as a key. The serial number is never stored but is retrieved dynamically each time, ensuring high security. Encryption is performed using SHA-256 to generate a unique key for each USB drive.

## CobaltRedAlertDesktop
Software that using Pikud HaOref API for RedAlerts. (Israeli missile alert)

## CobaltScreenTime
Windows utility for managing and restricting computer usage time.  

## CobaltYT_dlp
Basic GUI for YT_dlp
